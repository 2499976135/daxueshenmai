# ⏳ 时光 · 倒计时与专注

一款**免费、开源、纯本地**的 Android 倒计时 + 专注计时 App。

纪念日倒计时、专注时长记录、学习数据统计，还能接入 AI 帮你分析学习状态。
**没有广告、没有会员、没有内购，数据只存在你自己的手机里。**

---

## 它能做什么

### ⏳ 倒计时
- 纪念日、生日、考试、节日，未来日期自动倒计时
- 支持「每年重复」，生日纪念日不用年年重建
- 点开任意一条进入**沉浸式大屏倒计时**，每条都能设置自定义背景图片

### ⏱️ 专注计时
- 科目 / 项目随你命名（高数、背单词、跑步…），每个都能设每日目标时长
- 开始 / 暂停 / 结束，番茄钟提醒，目标进度环
- 今日专注记录，零点自动切换新的一天

### 📊 学习统计
- **扇形图**：各科目时间占比，可切换 日 / 周 / 月
- **柱形图**：近 7 天专注时长
- **折线图**：近 30 天趋势
- 累计时长、连续专注天数、目标完成度

### 🤖 AI 分析（可选）
- 可接入你自己的 AI 接口（DeepSeek / OpenAI / 本地 Ollama 等），一键生成学习状态分析和建议
- 默认关闭；开启后也只发送**汇总统计数据**，不发送任何原始记录

## 下载安装

### 第一步：获取安装包

**方式一（推荐）——从 Releases 页面下载，无需登录**

打开 👉 [**Releases 页面**](https://github.com/2499976135/daxueshenmai/releases)

找到最新的 **时光 · 最新构建**，在下方 **Assets** 里直接下载安装包。

**方式二——从构建记录下载（需要登录 GitHub）**

如果 Releases 里暂时没有可用版本：

1. 打开 👉 [**Actions 页面**](https://github.com/2499976135/daxueshenmai/actions)
2. 点最上面一条带绿色 ✅ 的 **Build Android APK**
3. 拉到页面**最底部**，在 **Artifacts** 区域点 **shiguang-apk** 下载
4. 下载得到的是压缩包，解压后可见安装包

### 第二步：选对安装包

| 文件名 | 适用设备 |
| --- | --- |
| `app-arm64-v8a-debug.apk` | ✅ 绝大多数手机（2017 年之后的机型） |
| `app-armeabi-v7a-debug.apk` | 较老的 32 位手机 |
| `app-x86_64-debug.apk` / `app-x86-debug.apk` | 安卓模拟器、少数 Intel 平板 |
| `app-universal-debug.apk` | ☑️ 不确定机型就选它，全架构通用 |

### 第三步：安装到手机

1. 把选好的 `.apk` 文件传到手机（微信 / QQ / 数据线 / 网盘都可以）
2. 在手机上点击这个文件
3. 系统会提示「未知来源应用」或安全风险提示 → 选择**允许 / 继续安装**
   （因为本 App 没有上架应用商店，这是正常提示）
4. 安装完成，桌面出现「时光」图标

## 开始使用

- **倒计时**：底部「倒计时」→ 右上角「＋ 添加」→ 填名称和日期即可。点任意一条进入大屏倒计时，右上角按钮可换背景。
- **专注**：底部「专注」→ 选择科目，或先在「⚙️ 管理」里新建科目并设置每日目标 → 点「开始」。
- **统计**：底部「统计」查看图表，扇形图右上角可切换 日 / 周 / 月。
- **设置**：切换主题、配置 AI 接口、导入导出备份。

## 我的数据安全吗？

- 所有数据（纪念日、专注记录、设置）**只保存在你的手机上**。App 不联网、不上传、无广告。
- 唯一联网的情况：你主动开启「AI 分析」并点击生成时。
- ⚠️ 卸载 App 或清除应用数据会丢失记录，建议定期用「设置 → 导出备份」保存一个 JSON 文件。

## 技术说明

- 使用 HTML + CSS + JavaScript 编写，通过 Capacitor 打包成原生 Android 安装包
- **零第三方依赖**：所有图表均由内置的 Canvas 绘制，完全离线可用
- 适配手机竖屏与平板横屏，支持深色 / 浅色 / 跟随系统主题
- 提供多种 CPU 架构的安装包（arm64-v8a、armeabi-v7a、x86、x86_64、通用包）
- 完整源码在本仓库中开源，欢迎查看与改动

## 常见问题

**Q：为什么安装时提示有风险 / 未知来源？**
A：因为这是从 GitHub 直接分发的安装包，没有走应用商店审核签名，属于正常提示。选择继续安装即可。

**Q：到底该装哪个包？**
A：不确定就用 `app-universal-debug.apk`（全架构通用）；确定是新款手机就用 `app-arm64-v8a-debug.apk`，体积更小。

**Q：支持 iPhone 吗？**
A：暂不支持。iOS 无法通过安装包形式安装，必须有开发者账号与上架流程，所以本 App 仅提供 Android 版。

**Q：会收费或加广告吗？**
A：不会。完全免费开源，代码都在仓库里。

**Q：数据会同步到云端吗？**
A：不会。所有数据只在你自己的手机上。

**Q：怎么更新到新版本？**
A：下载新版本 APK 覆盖安装即可，原有数据会保留。

**Q：AI 分析必须用吗？**
A：不是，默认关闭，完全可选。不开启也完全不影响其他功能。
